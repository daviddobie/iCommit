# iCommit API

This is the deployable backend for the iCommit mobile app. The initial service exposes `GET /health` so Railway can verify that the service and its MySQL configuration are reachable before authenticated pairing and session synchronization are added.

## Railway configuration

Deploy this directory as the root of the Railway API service. Railway should run `npm run build` to build the service, `npm start` to launch it, and use `/health` as the health-check path. Add a `DATABASE_URL` service variable that references the MySQL connection URL generated by the database service. Do not commit a real database URL to this repository.
